# ことばのギルド v9統合版

日本語を手がかりに7列×6行の文字石をなぞる、小さな森の冒険です。主人公・相棒の選択から訓練、乱入による敗北、ギルド帰還まで遊べます。

## Windowsで起動

作業フォルダーで実行します。

```powershell
python -m http.server 8000 --bind 0.0.0.0
```

PCでは http://localhost:8000/products/word-guild/index.html を開きます。iPhoneはWindowsと同じWi-Fiへ接続し、Safariで `http://WindowsのIPv4アドレス:8000/products/word-guild/index.html` を開きます。IPv4アドレスはWindowsの `ipconfig` でWi-FiアダプターのIPv4を確認します。ファイアウォールやネットワークの設定は本作業では変更していません。接続できない場合は利用者がローカル配信の許可を確認してください。外部公開・有料サービス・App Store公開は行っていません。

Safariの共有メニューから「ホーム画面に追加」を選び、そのアイコンからも起動してください。HTTPのローカル配信は確認用です。オフライン配信は実装対象に含めていません。

## 遊び方と今回の変更

- 男女の主人公は能力が同じ。炎・水・草の相棒を選び、合算HP100で出発します。選択と訓練完了を端末内へ保存します。
- 横・縦の隣接マスへスライドし、指を離すと判定。斜め・非隣接・同じ場所での滞留は追加しません。CATWから直前のTへ戻るとCATに短縮します。別経路を通った再訪は追加します。
- cat横、dog縦、sun横、ant曲がる経路で進みます。通常ボス「動物」はcat・dog・antの異なる2語。再入力では進捗が増えません。
- 通常戦闘は10秒ごとに相性で1/2/3ダメージ、30秒ごとに10回復。最低1HPの保護があり、誤答のダメージはありません。
- 新しい正解なし15秒で、通常敵・通常ボスの未発見語の一経路を順に光らせます。正解でリセット。入力や攻撃・回復の時計は続きます。
- 乱入ラスボスは専門語の日本語問題を敵側に表示。しるべは驚くだけで助言しません。入力可能になってから10秒又は異なる2語の早い方で即死し、以後回復しません。
- 一本の傷は従来から約35％拡大。文字は柄・影・輪郭線なしの単色です。v8の12キャラ78姿、既存の6階層・木石装飾に、v9の後ろ斜め歩行20姿と凍結3層を組み込みました。
- 通常ボス撃破後はギルドへの帰還相談、道の異変と凍結、しるべと番人の困惑、乱入の順に進みます。
- 敗北後「ギルドへ戻る」を押すと、ダンジョン出口→森の街道→ギルド遠景→石畳へ落下。3.5秒の演出後に帰還会話と完了保存を行います。
- 非表示では時計・音楽を停止し、復帰時に現在の場面から再開します。停止前の時間を大量の攻撃に換算しません。

## 音楽

最初の開始ボタン又は音楽ボタンで再生。ヘッダーのボタンで停止・再開・読み込み失敗後の再試行ができます。

ホーム・選択は「なんでしょう？／KK」、道中と階層移動は「Breeze3／PeriTune」、通常ボスは既存「Flap2／PeriTune」、乱入は「Raid／PeriTune」。HP0から吹き飛び・落下・着地まではBGMなし、飛行開始で風の「ヒュー」効果音。ギルド帰還後はホーム曲です。前の曲を停止してから新しい曲を再生し、遅れて読み込まれた古い場面の音源は再生しません。

[曲名・作者・公式出典・ライセンス・加工内容](assets/music/CREDITS.md)を同梱しています。旧作曲音源と楽譜は履歴として保持し、本番から参照していません。jabo1398という指定表記と公式Flap2の版の一致は未確認です。

## 自動検査

作業フォルダーから `python quality/run_v4_checks.py` でATELIER_CHECKS.jsonの登録8件を同じargvで実行します。ゲームルールはnode:test、実操作・音声・素材はPython Playwright、Python書式とコードはRuffです。ブラウザー検査は通常pytestから分離しています。Chromium専用shellがない環境では導入済みChromeを使用します。

個別例：

```powershell
node --test tests/word-guild.test.mjs tests/word-guild-transition.test.mjs
python quality/check_word_guild_browser.py
python quality/check_word_guild_claws_browser.py
python quality/check_word_guild_music_browser.py
```

検査結果はquality/v4-checks-results.json、操作の観測履歴とサーバー時刻は各結果JSON、画像はquality/screenshotsへ保存します。実ブラウザーはChromium/Chrome headlessです。iPhone Safariの実機を確認済みとは扱いません。

## 人の確認手順

1. iPhone 17・iOS 26.1のSafariとホーム画面起動をそれぞれ試し、開始・男女と相棒の選択、42マスの収まり、HPと会話の位置を確認。
2. 上下左右・曲がる入力、CATW→Tへの一歩戻し、斜め拒否、指を離す判定を試す。なぞってもページが動かないことを両起動方法で確認。
3. 通常ボスで異なる2語・重複無効、15秒の発光ヒントを確認。乱入は助言なしで10秒又は2語でHP0となることを確認。
4. 帰還ボタンから四景の移動とギルド会話を確認。同じ起動方法で終了・再起動して選択と完了が残ることを確認。Safariとホーム画面間の保存共有は前提にしていません。サイトデータ削除で保存は失われます。
5. 音楽の開始・停止・場面切替、背景へ移した時の停止と復帰を確認。音量、音のつながり、曲の好みを聴いて評価。敗北画面でBGMが止まり、飛行開始でヒュー音が一度鳴り、着地で止まることも確認。
6. 動きを減らす設定で帰還先の景色が変わることを確認。細かなドット、傷と文字の見やすさ、キャラの魅力、専門語の難度、15秒の待ち時間の好みを確認。

今回の確定条件は最新human_feedbackが古いspec・acceptanceより優先します。旧仕様ファイルは履歴として変更していません。変更と受入根拠の対応はquality/REPORT.mdに記載します。


音源の取得に失敗した場合は「音楽を再試行」をタップしてください。再生成功時には音楽のエラー文が消え、ボタンが「音楽を停止」に戻ります。保存や素材のエラー文は音楽の再生では解除しません。PCで通信失敗を再現する手順は `python quality/check_word_guild_music_browser.py` に含めており、503→再試行の実操作と表示、古いロード要求、保存失敗の表示を検査します。実機で通信が戻った際にも同じ表示になることを確認してください。


## 表示とBGMの改善 v6

背景は最大960×640のWebP、キャラは原寸lossless WebP、装飾6点は原寸・品質95のv7 WebPです。装飾も透明度・寸法は保持しています。受領PNGは全て保持しています。キャラは受領したv8の12役78姿を256pxの可逆WebPで組み込み、冒険ボタンは本・葉の外形に沿って透過させました。帰還素材は起動時に一括取得せず、次階層と帰還の素材をプレイ中に段階的に準備します。未準備の表情は読み込み済みの待機姿を表示し、decode後に切り替えます。

道中4階層とその移動中は同じBreeze3の再生位置を保持します。通常ボスでFlap2、乱入でRaidへ切り替えます。明示的に停止した後の再開、非表示からの復帰はこれまで通り現在の曲の先頭から再開します。

## 検査登録の事前確認（2026-10-07）

## 会話しながら遊ぶ版（2026-10-08）

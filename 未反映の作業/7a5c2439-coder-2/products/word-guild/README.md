# ことばのギルド v10

日本語を手がかりに7列×6行の文字石をなぞる森の冒険です。主人公と相棒の選択、訓練、乱入、しるべの救出、ギルド帰還、通常ボスの仲間加入まで遊べます。

## WindowsとiPhoneで起動

作業フォルダーで実行します。

```powershell
python -m http.server 8000 --bind 0.0.0.0
```

PCでは http://localhost:8000/products/word-guild/index.html を開きます。iPhoneは同じWi-Fiに接続し、Safariで `http://WindowsのIPv4アドレス:8000/products/word-guild/index.html` を開いてください。IPv4はWindowsの `ipconfig` のWi-Fiアダプターで確認できます。ネットワーク・認証・ファイアウォール設定は変更していません。外部公開はしていません。

Safariの共有メニューから「ホーム画面に追加」し、そのアイコンからの起動も確認してください。ローカルHTTP配信は確認用で、オフライン対応は含みません。

## 遊び方

- 男女の主人公は同じ能力。炎・水・草の相棒を選び、合算最大HP100で出発します。
- 横・縦の隣接マスへスライドし、指を離すと判定します。斜め・非隣接・同じ場所での滞留は追加しません。CATWから直前のTへ戻るとCATに短縮し、別経路から再訪すると追加します。
- 猫はcat横、犬はdog縦、太陽はsun横、アリはantの曲がる経路です。通常ボスの課題「動物」はcat・dog・antの異なる2語で撃破。同じ語では進捗が増えません。吹き出しへの答えの箇条書きはありません。
- 通常戦闘は10秒ごとに相性で1/2/3ダメージ、30秒ごとに10回復。最低1HPの保護があり、誤答では無傷です。正解なし15秒で未発見語の経路が光ります。
- 通常ボス撃破後は帰還相談→道の異変と凍結→困惑→乱入。乱入ボスは難語を出題し、操作可能な戦闘開始から10秒または異なる2語で一撃を放ちます。初めから文字のヒントが光り、しるべは驚くだけです。
- 一撃と赤いダメージ数字でHP0を表示した後、しるべが「ここから逃します！」と話します。一度だけHP10へ救出回復し、「うまく着地してくださいね！」と送り出します。帰還ボタン操作は不要です。この間は攻撃・通常回復・回答を停止します。
- 主人公の飛行中は「うわああああああ」だけを一度発話し、BGMが止まり風音が鳴ります。主人公の着地後に通常ボスが飛来・着地して仲間になり、以後の案内役を担当します。選択した相棒・属性・最大HPは変わりません。
- 声の停止・取得失敗でも物語は自動で進みます。非表示中は声・音・物語と戦闘の時計を停止し、復帰時に現在の場面から再開します。

## 声・音楽・保存

最初の開始タップで声と音楽が有効になります。声と音楽はヘッダーから個別に停止・再開でき、声は途中位置から再開します。会話中でも盤面を操作できます。音楽・声の取得失敗はそれぞれの再試行ボタンで再試行してください。

ホーム・選択は「なんでしょう？／KK」、道中と移動は「Breeze3／PeriTune」、通常ボスは「Flap2／PeriTune」、乱入は「Raid／PeriTune」。同じ道中曲は階層移動で再生位置を保ちます。HP0から救出・飛行・加入まではBGMなし、ホーム帰還でホーム曲に戻ります。[音楽の出典と利用条件](assets/music/CREDITS.md)、[音声の配役・生成条件](assets/voice/CREDITS.md)、[収録表](assets/voice/manifest.json)を同梱しています。製品は外部AIサービスに接続しません。

主人公・相棒・訓練完了・通常ボス加入・しるべとの別離を端末内に保存します。加入後は再起動・選択・再プレイでも通常ボスが案内し、しるべは表示・発話されません。旧保存の完了フラグだけから加入済みとは判断しません。保存キーとversionは従来と同じです。同じ起動方法で保存を確認してください。Safariとホーム画面の保存共有は前提にせず、サイトデータ削除では保存も失われます。

通常ボス・乱入ボスは現在の表示名です。「獅子」「黒魔導士」は命名の提案として残し、採用済みとは扱いません。しるべとの終盤の再会・続章は今回含みません。

## 再現用シーンと状態表示

通常URLには操作APIを公開しません。凍結された読み取り専用 `window.wordGuildState` に、HP・入力・盤面・音響・会話・`phase`（演出時計）・`storyState`（救出実施、加入、しるべ登場可否、案内役）を表示します。`elapsed` は戦闘時計で、演出時計とは別です。`window.wordGuildAssets` は画像decode状態の読み取り専用情報です。

例：`http://localhost:8000/products/word-guild/index.html?dev=1&scene=rescue`

`scene=home/select/cat/dog/sun/ant/animal/final/defeated/travel/returning/freezing/bewildered/arriving/intrusion/counter/loss/escape/rescue/sendoff/launch/fall/land/bossArrival/bossLand/recruited/return` を再現できます。開発URLだけにシーン切替・時計操作があり、保存はメモリへ隔離します。左上の「開発確認」で状態を読めます。各シーンの設定値は確認用で、自然な攻略の検査とは区別します。

## 自動検査

作業フォルダーから実行します。

```powershell
python quality/run_v4_checks.py
python -m pytest -q
```

登録8件を同じargv・timeoutで実行し、Nodeルール・会話・音声、実ブラウザー操作、素材・音響・画像速度、全体Ruffを確認します。単独の救出検査は `python quality/check_word_guild_rescue_browser.py`、自然な全攻略・声停止・503の物語検査は `python quality/check_word_guild_story_v9.py`。結果は `quality/v4-checks-results.json`、`quality/rescue-v10/results.json`、`quality/story-v9/results.json`。ブラウザーはローカルChrome/Chromiumで、iPhone Safari実機の代わりとは扱いません。プレーンESモジュール構成のため型検査・バンドルビルドはありません。

背景・キャラの原画と既存のWebP・歩行・凍結・一本の傷・石の崩落・BGMを保持しています。読み込みは次場面を順に準備し、未準備の表情は待機姿で補います。画像速度の測定は音源転送を遮断した比較で、音声ありの実操作は別の検査です。

## 人の確認手順

1. iPhone17/iOS26.1のSafariとホーム画面からそれぞれ起動し、男女・3属性の選択、42マス・HP・下側字幕が収まることを確認します。
2. 実指で上下左右・曲がる入力、CATW→T、滞留、斜め拒否、離指の判定を試します。なぞり中にページ全体が動かないことを両起動方法で確認します。
3. 通常ボスで異なる2語・重複無効を試し、帰還相談・凍結・困惑・乱入を見ます。乱入10秒と2語の両経路で一撃→HP0→救出宣言→HP10→着地の注意→飛行→主人公着地→通常ボス飛来・加入を確認します。
4. 加入後のホーム・選択で通常ボスが案内し、しるべが現れないことを確認します。同じ起動方法で終了・再起動し、選択・完了・加入・別離が保持されることを確認します。
5. 声と音楽を個別に停止・再開し、救出中の声停止でも物語が進むこと、画面ロックや別アプリへの移動中は止まり、復帰後に古い声が割り込まないことを確認します。
6. 相性不利の通常戦闘で10分以上待ち、攻撃・回復と生存を確認します。動きを減らす設定でも一撃・HP変化・帰還先・加入が分かることを確認します。
7. 女性しるべの声質、各役の日本語・英語の読み、叫び、掛け合いの間、BGMとの音量とループを聴きます。Flap2の指定版との一致、創作台詞・配役・名称・造形の好み、実回線の初回読み込みと長時間の安定性も人の確認です。

最新の確定依頼を旧仕様より優先しています。差分・受け入れ条件・実装・検証の対応と未確認事項は `quality/REPORT.md` に記録します。

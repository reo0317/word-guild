# 森の本のギルド — 制作方針

## 世界と色
言葉を集める小さな書庫が、深い森に灯りをともす。ホームは専用の整数座標ドット絵。遠い樹木、木組みの書庫、重なる瓦、窓の蜂蜜色の灯り、本の旗と看板、花鉢、石畳を前後に重ねる。既存の専門素材を原画として残し、新しい背景・表情素材は products/word-guild/assets に制作する。

深い青緑 #173e40 と #0e292e、クリーム #fff3d6、蜂蜜 #f4c66c を基本色とする。文字の背後には不透明な面を設ける。開始・出発だけを蜂蜜色にし、選択・戻る・音楽は控えめな木製札として区別する。

## 画面
ホーム：小さなブランド → 森の書庫のタイトル → 大きな場面絵と主人公・相棒 → 案内係の吹き出し → 開始。スマホで説明は2行程度に抑える。
選択：主人公2枚・相棒3枚のカード。大きな姿、固有名、短い性格、選択マーク。男女は共通HP50。相棒は炎・しずく・葉の形と文字でも属性を示す。
戦闘：階層名 → 奥行きのある風景と大きな敵 → パーティー → 案内係の吹き出し → 入力 → 太いHP → 7×6盤面。最小320×568でも全42マスを操作領域内に収める。PCでは中央に縦長の冒険帳として表示する。

## キャラクターと反応
既存のオリジナル原画から、細部の陰影・衣服の縫い目・目のハイライト・頬・小道具を追加した64px原画と4表情を制作。瞬き、喜び、困り顔を実フレームで切り替える。炎は跳ね、水は揺れ、草は葉を振り、猫・犬・太陽・アリ・番人・ことば喰いは固有の待機動作。案内係は本と星の杖を持つ。
選択は即座に枠とチェックに反映。正解は爪痕と蜂蜜色の光、誤答は短い困り顔、被弾は赤い数字とHPの反応、回復は緑の数字と案内係の光。石の崩落・道の移動・落下は既存時間を維持し、最終石の着地まで入力を停止。敗北から帰還は同じ森の書庫へ着地する。
prefers-reduced-motionでは移動・揺れ・瞬き等を抑制し、結果は静止表情と色・文字でも伝える。

## 維持する仕様と検証
今回の確定した仕上げ方針に従い、入力は上下左右の隣接マスだけに戻す。斜めと非隣接移動は文字を追加しない。sunの保証経路は24→25→26の横方向。曲がる経路、一歩戻し、再訪、42マス、属性・HP・時計、2語または45秒の裏ボス、音楽、保存、帰還の順序を維持する。森のギルド、12キャラの4表情、6階層の背景と演出はそのまま使う。旧仕様の斜め条件は履歴として保存し、今回の検査条件には使わない。スマホ幅とPC幅で主要操作・正解・爪痕・次階層を実操作し、タッチの斜め拒否とキャンセルも検査する。
開発専用URL ?dev=1&scene=… にのみ再現シーンを用意。通常URLには操作用デバッグAPIを出さない。状態表示はJSONの読み取り専用スナップショット。開発シーンでは保存を隔離する。
Python PlaywrightのローカルHTTP配信で390×844、320×568、PC幅を撮影し、画像を実際に開いて確認。開始・カード選択・盤面のPointer Events・一歩戻し・正誤・全階層・ボス・帰還・再読み込みを操作検証する。iPhone Safari・ホーム画面・聴感は人へ引き継ぐ。

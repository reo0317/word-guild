# 語彙リストの原本

配布元から 2026-11-11 に取得したファイルを、手を加えずに置いています。取り込みは `tools/import-words.mjs`（M2 で作成）で行い、ここのファイルは書き換えません。

| ファイル | 内容 |
|---|---|
| `TSL_12_stats.csv` | TOEIC Service List 1.2 の見出し語1,250語。順位・SFI・U（ISO-8859 の文字コード） |
| `TSL_12_lemmatized_for_teaching.csv` | TSL の見出し語と派生語（学習用。先頭の `##` 行は注記） |
| `TSL_12_definitions.xlsx` | TSL のやさしい英語による定義 |
| `TSL_12_alphabetized_description.txt` | TSL のコーパスの説明 |
| `NGSL_12_stats.csv` | New General Service List 1.2 の見出し語2,809語。順位・SFI・U |
| `NGSL_12_lemmatized_for_teaching.csv` | NGSL の見出し語と派生語 |
| `NGSL_12_with_English_definitions.xlsx` | NGSL の英語による定義 |
| `NGSL_12_alphabetized_description.txt` | NGSL の説明 |

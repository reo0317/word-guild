# Tripo に渡すもの（人とフクロウの 3D 化）

ねらい：ツムギ・フウロウ・ハトリ局長を 3D にして、タイトル画面と英文の紙芝居の絵（静止画・短い動き）を作る。
3D は「絵を作るための人形」として使う。ゲームに 3D をそのまま入れるのではなく、ポーズとカメラを決めて画像に書き出し、版画風に仕上げる。

## 入っている画像（白背景・1024×1024・正面）

| ファイル | だれ | Tripo での扱い |
| --- | --- | --- |
| `tsumugi-front.png` | ツムギ（主人公） | 人型。自動リグ（骨入れ）を付ける |
| `hatori-front.png` | ハトリ局長 | 人型。自動リグを付ける |
| `fuurou-front.png` | フウロウ（郵便フクロウ） | 動物。リグなしでよい（羽ばたきは後で付ける） |

- 横・後ろの絵（多方向）は、明日 8:01 以降に画像生成で `tsumugi-side.png`・`tsumugi-back.png` などをこのフォルダーに足す。Tripo に「複数の画像から作る」機能があれば、正面・横・後ろをまとめて渡すと形が安定する。
- 今の正面の絵は腕を下ろした立ち姿。リグを付けるとき腕が体にくっつく場合は、明日の多方向の絵（腕を少し離した A ポーズ）を使う。

## Tripo での設定の目安

- 作り方：画像から 3D（Image to 3D）。多方向の絵がそろったら多方向から 3D。
- テクスチャ：あり（色を絵から写す）。つやは無し・控えめ。
- 面の数：少なめ（人型で 2〜3 万面くらい）。細かすぎると版画風に仕上げにくい。
- 人型（ツムギ・ハトリ）：自動リグ（Auto Rig）を付ける。歩く・手を振るなどの動きを付けられるようにする。
- 書き出し形式：**GLB**（テクスチャ込みの 1 ファイル）。

## 返してほしいもの

- `tsumugi.glb`、`hatori.glb`、`fuurou.glb`（リグを付けたものはリグ付きのほう）
- チャットに添付してもらえれば、こちらで `3d/models/` に置いて使う。

## こちらでやること（受け取ったあと）

1. Three.js でモデルを読み、トゥーン調の陰影と太い紺の輪郭線を付ける（ゲームの版画風に合わせる）。
2. 紙芝居：場面ごとに「ポーズ・カメラ・英文の字幕」を台本にして、場面の絵を書き出す。
3. タイトル画面：霧の坂道でツムギが手紙を持ち、フウロウが飛ぶ場面を 1 枚（または数秒の動き）にする。
4. iPhone で重くないように、ゲームには書き出した画像を入れる（3D はゲーム内では動かさない）。
